Configurar acesso ao Google Drive

Crie um OAuth Client ID do tipo Aplicativo da Web no Google Cloud, habilite a Drive API e adicione o endereço exato do seu GitHub Pages em Origens JavaScript autorizadas (ex.: https://community-base.github.io). Não use segredo de cliente neste HTML.

Escopo solicitado: https://www.googleapis.com/auth/drive.readonly. Pode exigir verificação do aplicativo pelo Google para uso público. Tokens de acesso ficam apenas em memória; o Client ID não é secreto.
